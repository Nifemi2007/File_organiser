# File Organiser

This organise the files in a folder according to the file_extension

## How to use

- The folder you want to organise should be inside the FILE_ORGANISER folder
- Subtitute the "FOLDER_NAME" with the folder you want to organise
- Run "python main.py" on the terminal
- A folder named Organised_files is created and it contains your files organised according to the file_extension of the files
